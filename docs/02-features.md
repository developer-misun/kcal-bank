# 02. 기능 명세

프로토타입(`prototype/index.html`)과 같은 구성. 탭 3개: **식단 · 영양 참고 · 목표**. 모바일 한 열 레이아웃, 라이트/다크 모드.

## 공통 헤더
- 제목: `{하루 목표 kcal} 식단 기록장`
- 날짜 이동: ‹ yyyy-mm-dd › (오늘 이후로는 못 감)

## 1. 식단 탭
위에서 아래 순서:

### 1-1. 칼로리 게이지
- 오늘 먹은 kcal / 목표 kcal, 진행 막대 (초과 시 빨강)
- 알약 표시: "N kcal 남음" 또는 "N kcal 초과". 최소 칼로리 미만이면 "· 최소 1,200까지 N" 덧붙임
- D-n 배지 (목표 탭의 시작일 기준)
- 작은 칸 3개: 기초대사량 · 워치 활동 · 이번 주 저금통 (+초록 / −빨강)

### 1-2. 영양소 (기준 대비)
- 제목 옆에 현재 기준 이름 꼬리표 (예: "맞춤: 감량·건강")
- 하루 평가 이모티콘 한 줄 (예: "🙂 괜찮아요 · 기준 5/7 통과"). 규칙은 `04-rules.md`
- 6줄: 탄수화물, 단백질, 지방(열량 대비 %, g도 같이), 식이섬유, 당류, 나트륨
- 각 줄: 이름 · 막대 · 값 · 기준 문구 (예: "60g 이상")
- 색 규칙은 `04-rules.md`
- 아래 안내문: 영양소 정보가 없는 음식이 몇 개 빠졌는지, 추정값 안내

### 1-3. 먹은 음식
- 끼니별 묶음: 아침 · 점심 · 저녁 · 간식, 끼니 합계 kcal
- 음식 줄: 이름(양 포함, 예: "장어구이 135g") · kcal · 삭제(×)

### 1-4. 버튼 두 개: [+ 음식 추가] [워치 · 체중]
화면에 입력 폼을 펼쳐 두지 않고, 버튼을 누르면 **아래에서 올라오는 팝업(바텀시트)**으로 입력한다.

**음식 추가 팝업**
- 끼니 선택(현재 시간으로 자동: 10시 전 아침, 15시 전 점심, 17시 전 간식, 그 뒤 저녁), kcal, 음식 이름(양 포함)
- "영양소 (선택)" 펼치면: 탄수화물·단백질·지방·식이섬유·당류·나트륨
- 추가하면 팝업이 닫힌다. 바깥이나 ×를 누르면 닫힘

**워치·체중 팝업**
- 워치 활동 kcal (저금통 보너스에 사용)
- 체중 kg (주 1회, 월요일 아침 공복 권장)
- 입력하면 버튼 글자가 "워치 207 · 64.6kg"처럼 바뀐다

### 1-6. 목표 체중 진행
- "최근 체중 59.5kg · 4.5kg 남음 (시작 60kg)" + 진행 막대

### 1-7. 지난 기록
- 최근 30일: 평가 이모티콘 · 날짜 · 미니 막대 · kcal · 체중
- 체중 칸은 **시작 체중 대비 변화**("−2.4kg")로 보여 주고, 그 칸을 누르면 실제 체중("64.6kg")으로 바뀐다(다시 누르면 원래대로)
- 체중 칸 말고 줄의 다른 곳을 누르면 그 날짜로 이동

## 2. 영양 참고 탭
목적: 재고 관리가 아니라 **"부족한 영양소를 어떤 음식으로 채울지" 찾는 참고 자료.**
- 영양소 버튼 5개: 단백질 · 식이섬유 · 당류 적은 · 나트륨 적은 · 포화지방 주의
- 고른 영양소 기준 **Top 10** (1회 기준량): 막대 + 값. 단백질·식이섬유는 "100kcal당 n g"도 표시
- 아래에 분류별 전체 목록 (단백질 / 채소·과일 / 밥·면·곡물 / 유제품 / 간식·음료 / 양념·기타)
- 항목 누르면: 영양소 8칸(탄·단·지·당·포화지방·식이섬유·나트륨·kcal), 메모, **"+ 오늘 ○○에 기록"**(시간대로 끼니 자동, 영양소도 함께 저장), 삭제(두 번 눌러 확인)
- 각 항목에 "성분표" / "추정" 꼬리표
- 음식 추가 폼: 이름, 분류, 기준량, kcal, 소비기한(선택), 영양소(선택), 출처

## 3. 목표 탭
### 내 정보
성별, 나이, 키, 활동량 (거의 앉아서 ×1.2 / 가볍게 ×1.375 / 보통 ×1.55 / 활발 ×1.725)

### 체중 목표
시작일, 시작 체중, 목표 체중

### 자동 계산 카드 (입력하는 즉시 갱신)
- 기초대사량 (최근 체중 기준)
- 하루 소비 추정
- 추천 목표 칼로리 범위
- 지금 목표로 주당 감량 예상, 목표까지 주 수

### 하루 칼로리
하루 목표, 최소. "추천 목표 칼로리 넣기" 버튼.

### 영양소 기준
"맞춤: 감량·건강" 또는 2025 한국인 영양소 섭취기준의 연령·성별 그룹 (21가지)

### 저금통
워치 보너스 기준 kcal

### 저장 + 경고
- 목표가 최소(여 1,200 / 남 1,500)보다 낮으면 경고
- 주 1kg 넘게 빠지는 속도면 경고

## 나중에 넣을 기능 (MVP 이후)
- 대화형 기록 ("만두 4개 먹었어" → 자동 기록), 음식 사진 인식, 성분표 사진 OCR
- 공공 식품영양성분 DB(식약처) 검색 연동
- 주간·월간 리포트, 체중 그래프
- 백업/내보내기 (JSON, CSV)
- 워치·건강 앱 연동 (Health Connect, HealthKit)
