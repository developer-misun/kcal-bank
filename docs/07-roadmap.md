# 07. 로드맵

## 1단계 — MVP (안드로이드 비공개 테스트까지)
- [ ] 대시보드 탭: 기간 선택, 요약 칸, 칼로리·체중·저금통 그래프, 영양소 평균, 일자별 기록
- [ ] 식단 탭: 게이지, 영양소 막대, 끼니별 목록, 추가/삭제, 워치·체중
- [ ] 영양 참고 탭: 영양소별 Top 10, 분류별 목록, 오늘 기록에 추가, 음식 추가
- [ ] 목표 탭: 내 정보, 체중 목표, 자동 계산, 영양소 기준 선택, 저금통 기준
- [ ] 로컬 DB 저장, `data/master/` 시드, `data/logs/` 가져오기
- [ ] 계산 로직 단위 테스트 (`docs/04-rules.md`)
- [ ] JSON 내보내기/가져오기 (백업)
- [ ] 의료 조언 아님 안내, 개인정보처리방침
- [ ] Google Play 비공개 테스트 (12명, 14일)

## 2단계
- [ ] 식약처 식품영양성분 DB 검색 (공공 API)
- [ ] 주간 리포트, 체중 그래프
- [ ] 음식 기록 시 양(g) 입력하면 영양소 자동 환산
- [ ] iOS 배포

## 3단계 — AI 기능
- [ ] 대화형 기록, 음식 사진 인식, 성분표 사진 읽기
- [ ] 부족한 영양소에 맞춘 메뉴 추천 (싫어하는 음식 제외 등 개인 규칙)
- 주의: AI API 키를 앱에 넣으면 안 됨 → 서버 필요, 사용량 비용 발생

## 아직 정하지 않은 것
- **기술 스택**: 후보
  - Flutter — 한 코드로 안드로이드·iOS, 성능 좋음
  - React Native (Expo) — 웹 프로토타입(HTML/JS) 로직을 옮기기 쉬움
  - 안드로이드 네이티브(Kotlin) — 안드로이드만 먼저라면
- 로컬 DB: SQLite / Realm / Hive 등
- 앱 이름, 아이콘
- 워치 연동 방식 (Health Connect / HealthKit) 또는 수동 입력 유지
