# 06. 스토어 배포 체크리스트

2026-10 기준으로 찾아본 내용. 배포 직전에 각 스토어 정책을 다시 확인할 것.

## Google Play
- 개발자 등록비: 1회 25달러
- **개인 계정은 정식 출시 전 비공개 테스트 필수: 테스터 12명이 14일 동안 참여** (예전 20명에서 12명으로 바뀜)
  - 테스터 12명을 미리 모아 둘 것
- 건강 앱 정책, 데이터 보안(Data safety) 양식 작성

## App Store
- Apple Developer Program: 매년 99달러
- 건강 관련 문구·기능 심사가 까다로운 편

## 공통 준비물
- [ ] **개인정보처리방침 URL** (무료 앱도 필수. 체중·식단은 건강 데이터)
- [ ] 앱 안에 **"의료 조언이 아닙니다"** 안내
- [ ] 데이터는 **기기 안에만 저장** → 개인정보 부담과 Data safety 작성이 쉬워짐
- [ ] 백업/내보내기 기능 (기기 교체 대비)
- [ ] 앱 아이콘, 스크린샷, 설명문 (한국어)
- [ ] 영양 기준·식품 DB 출처 표기 (2025 한국인 영양소 섭취기준, 식약처 식품영양성분 DB를 쓰면 출처)
